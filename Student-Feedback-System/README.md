# Student Feedback Management System

A web application for collecting and managing student feedback.

## Technologies
- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MongoDB

## Features
- Student feedback submission
- Feedback stored in MongoDB
- Admin feedback viewing
- Feedback management
- Simple and user-friendly interface

## How to Run

1. Open the project in VS Code.
2. Install dependencies:

npm install

3. Create a `.env` file:

MONGODB_URI=mongodb://127.0.0.1:27017/FeedbackDB
PORT=3000

4. Start the server:

node server.js

5. Open:

http://localhost:3000
